# 50 次配对公司组 bootstrap：冻结协议

用户授权将既有 8 次扩展至 30–50 次，本次固定完成 **50 次**，不按结果提前停止。复用原始 0–7 次，新增 8–49 次，每次各拟合 q2 和 unrestricted；共 84 次新增拟合。原运行 `xai_rsf_interpretable_baselines_v1_20261027_hw9gdrol`、正式作业 2530 为复用来源。原报告不改写。

## 保持不变的对象

制造业训练原点 2012–2020、拟合截止 2022-01-01，训练 56,458 条、2,577 公司组；已接触的 2023/2024 企业仅用于固定解释锚点及既有预测输出。仍为 **PROVISIONAL、事后探索性**；不是新盲测。公司组按种子 `8000+r` 有放回抽取，保留组内全部记录；重复抽中的公司使用克隆组标签，沿用原 8 次算法，不将这些标签说成新的独立企业。森林随机种子固定 42，不评价跨随机种子的全部不确定性。

两配置完全沿用原方案：32 棵树，深度 6，支持约束相同。q2 为二阶路径限制、共享分位数切点、每树 25 字段；黑箱为无阶数限制、局部随机切点、全部字段。同一后端，**并非只改变 q 的单因素消融，也不是 M2**。不新增超参数搜索，不重训 EBM。

用原来的 32 个固定企业锚点、16 行固定训练背景、365 天目标 CIF，计算两模型的精确有限联合行背景 Shapley 贡献。两个模型用完全相同的解释定义，排除近似 SHAP 的计算噪声。q2 的原生二阶函数分解另外做精确重构核验；不要将 Shapley 特征归因稳定性等同于原生交互结构稳定性。

## 主要估计量和区间

每个企业的 75 维贡献先除以其 L1 范数（下限 `1e-15`），然后计算两个重训模型之间的 RMSE。主要指标为此归一化 RMSE，避免仅因风险/贡献幅度较小显得稳定。辅助指标：原始 RMSE、重要性 Spearman、Top10 Jaccard、符号一致率及企业内相关系数中位数，均复用旧 `compare` 实现。Top10 沿用固定字段顺序打破并列；如有零贡献并列，其局限保留。

令 `h(b,c)=metric(q2_b,q2_c)-metric(bb_b,bb_c)`，报告所有 `b<c` 的平均值 U。50 次产生 1,225 对，**独立单位只有 50 个配对重训结果**。删掉第 b 个重训结果及其全部关联边，得 U(-b)：

`SE² = (B-1)/B × sum_b [U(-b) - mean(U(-b))]²`

95% 区间为 `U ± t(0.975,B-1) × SE`。这是固定原训练样本、随机种子、解释锚点和背景后的**条件 bootstrap 稳定性泛函的 Monte Carlo 估计区间**，采用非退化 U 统计量的渐近 jackknife 近似。不是 1,225 个独立观察的区间，不是跨原始总体样本/行业/时期的总体置信保证，也不是二层 bootstrap。若 jackknife SE 为零或非有限值，明确报告退化，不能制造显著性。主要指标预先指定；辅助指标区间为未作多重比较校正的描述性结果。

另外：每个重训模型与各自原始全样本模型比较，形成 50 个配对差值。报告均值的条件 Monte Carlo t 区间，以及差值自身 2.5%–97.5% 分位数区间；后者称为**重训差值分布区间**，不称为均值置信区间，50 次不足以精确估计尾部分位数。

旧报告为 8 次产生的 28 对的中位数。本次为适用配对 U 统计量推断，主报告改用平均差值，同时保留两模型中位数、配对差值中位数及 8/30/50 次固定前缀摘要，不能混用两种统计量。固定停止在 50 次，30 次仅作敏感性描述。

误差指标差值 < 0 有利于 q2；相似度指标差值 > 0 有利于 q2。稳定性优势不能证明解释为因果、原生函数统计可辨识、预测非劣，或修复原模拟交互恢复不足。

公式参考：[UW-Madison, Jun Shao, Stat 710 Lecture 23](https://pages.cs.wisc.edu/~shao/stat710/stat710-23.pdf)，第 4 页 jackknife 方差公式。本任务的条件估计对象和限制由本协议明确，不将该公式视为任意有限样本覆盖率保证。
