# EBM基线有效性限制：本轮出现严重过拟合

seed42的EBM-GAM、GA²M-10、GA²M-30训练加权logloss分别约0.00482、0.00248、0.000559；后期风险>99%的记录分别86、83、88条。GA²M-10的合并Brier约0.01764，明显高于q2的0.00950。这种训练拟合极强、后期概率失真的模式支持过拟合诊断，不能只将其归因为“EBM不适合生存问题”。具体机制还可能受年份漂移、分箱稀少事件支持和输入版本限制共同影响，未在本轮分别识别。

固定轮数原本用于避免按记录随机内部验证造成同公司泄漏，并保持实验有限；然而它没有提供有效的训练期复杂度选择。这是本次比较设计的限制，而不是充分公平强基线已经建立。未来若要做强基线结论，应仅在训练期采用公司分组/时间内验证与早停或正则化，并冻结之后再评价；本轮不追加这项训练，也不以2023/2024指标选择轮数。
