# 可解释基线、结构恢复和SHAP的有限对照

用户明确选择继续使用制造业2023/2024，全部为后暴露探索性比较。沿用56,458条制造业训练记录、拟合截止2022-01-01，以及同一23,799条评价记录；不改变ST、竞争事件、删失、行业代理或未知结局规则。既有PIT和随访限制仍为PROVISIONAL。不得称独立测试，不扩展超参数搜索。

## 1. EBM/GA²M式基线与精度—复杂度图

EBM是实现框架，GA²M是主效应加二元交互的模型形式，二者不是两个彼此独立的算法。新增同一InterpretML实现的三种冻结配置：纯主效应、自动选择10对交互、自动选择30对交互。各3个种子42/101/202，共9模型。max_bins32、max_interaction_bins16、max_rounds2000、学习率.03、greedy_ratio0、主/交互smoothing50、min_samples_leaf20、max_leaves3、outer_bags1、validation_size0、单线程。不使用按记录随机的内层验证，避免同公司季度记录串入；固定轮数、无后期调参，不宣称这是充分调优的最优EBM。

目标为12日历月内首次目标ST的概率，已观察竞争事件是已知非目标，未知结局权重为0。训练使用原源一致性reverse-KM IPCW（仅训练数据计算），无重标未知结果为正常。它是IPCW端点分类基线，不提供完整竞争风险曲线或原因概率守恒。森林可利用部分随访而端点EBM通过IPCW利用完整端点，损失/信息利用不同。比较预测目标一致，不宣称估计器相同。

复用q2/q3/q4、同后端不限阶数森林和原全行业M2；M2不重训且不冒充制造业模型。报告年度/合并、记录/公司等权AUC、AP、Brier、校准、Top20/25、提前3/6月。合并AP在合并预测重算。

前沿横轴为完整原生函数表的空间标量格数（对数轴），另列函数数量、最高阶数、链接函数和稳定性。森林展示目标365日CIF的原生分解复杂度；EBM展示log-odds函数表，sigmoid后才是概率。因此这是声明尺度下的描述性复杂度前沿，不是统一心理可读性评分，也不能将EBM函数值写成CIF百分点。黑箱森林/M2不伪造“75个SHAP值就是75个全局函数”的复杂度点；其预测性能作为参考线。缺失和未见状态保留计数，不能用删去状态压低复杂度。

## 2. 已知结构模拟

七种DGP：additive_cif、pair_cif、triple_cif、additive_logit、pair_logit、correlated_pair、heavy_censor_pair。8个二值原始坐标，目标/竞争事件均由已知混合事件概率及指数时间生成，行政截止2；真目标CIF被直接控制。每种5次共同模拟种子42/101/202/303/404，训练3000、评价1000，共同数据给q2、q3、不限阶数森林、EBM-GAM、GA²M式EBM10对，共175拟合。森林32树、深度6、叶30记录/15组/3事件；8变量全部可候选、共享切点。模拟EBM固定1000轮，其他设置不变。

使用完整256点均匀二值网格及Walsh正交展开，计算所有阶数的真/预测概率函数系数，非恒零真项阈值1e-10，估计项预先固定效应阈值0.005概率单位；报告结构precision/recall/F1、二阶支持、系数RMSE、高阶能量、实际分布与均匀网格预测误差、真概率尺度Shapley恢复误差。另按每个模型原生尺度分别计算真/估计系数RMSE，不能跨CIF与log-odds直接比较其绝对值。

非线性logistic链接会在概率尺度诱导高阶项；这不是GA²M原生结构实现错误。相关场景的均匀乘积参考与观察分布不同，两类误差分列；不要把相关代理变量选择自动叫作因果结构错误。二值模拟是可精确审计的受控测试，不代表连续财务阈值恢复。五次重复仅作有限Monte Carlo描述。

## 3. 同一公司组重抽样下的解释稳定性

冻结8次训练公司组bootstrap，种子8000—8007，每次整组有放回抽样，重复公司拷贝使用克隆组ID。每次q2、不限阶数森林、GA²M式EBM10对读取完全相同的行索引，模型随机种子固定42，以尽量分离数据变化与算法随机变化，共24拟合。EBM在每次训练重抽样内重新估计IPCW。评价样本固定，不用评价结局指导抽样或调参。

原训练抽取16个背景公司各一条记录；原评价抽取32个固定公司各一条记录作为解释锚点，不按事件或模型风险挑选。森林原生函数固定在原训练参考边际下中心化，报告函数集合和固定锚点上的变化；EBM原生函数是log-odds。对q2和不限阶数森林，还在同一16行经验背景上计算精确interventional Shapley值，按共同重抽样比较概率尺度归因变化。原生二元项与SHAP单变量项不逐项冒充同一估计对象。

另外固定原seed42模型，仅将背景换成每个训练重抽样产生的16行背景，测背景敏感性；与重训敏感性分开。8次重抽样不是校准的95%置信区间，不宣称完整训练不确定性已充分刻画。

## 4. 黑箱SHAP忠实性与计算随机性

固定原q2和同后端不限阶数森林seed42、同16行背景、前12个固定解释锚点、365日目标CIF，使用官方shap.PermutationExplainer，3个解释器种子和1/8/32个双向排列循环，共18任务。

加和误差只是局部准确性，不等于Shapley近似已经收敛。单独报告相对精确有限背景Shapley参考的MAE/RMSE/最大误差、计算时间、不同解释种子的相关性/符号/Top-k重叠。官方PermutationExplainer本身保证加和，不能因此宣称本方法独占忠实性。

精确参考将每个叶区域写成原坐标指示函数乘积，利用Shapley线性性及排列积分求值：每个(x,b)中a个指示从0变1、b个从1变0，正贡献权重B(a,b+1)，负贡献权重-B(a+1,b)；任一恒0坐标使整个叶博弈恒0。按背景实际联合行求平均，不将经验联合背景偷换成边际乘积。已用全子集穷举及官方ExactExplainer独立测试。缓存标量森林遍历与原模型概率逐点核对。该参考算法是审计实现，不声称新的TreeSHAP方法创新。
