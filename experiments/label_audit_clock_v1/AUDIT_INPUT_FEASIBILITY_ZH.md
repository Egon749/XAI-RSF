# 全风险集审计信息接入的最小可行性检查

**存在有意义的提前信息候选，但当前尚未具备可直接启动匹配训练的全风险集审计输入。** 这不是要求恢复所有财务数据PIT，而是限定在拟新增字段自身的来源、覆盖和公开时钟。

先检查登记schema和质量。远程只读MCP入口未连通，转用服务器已有只读Registry及本地字典／质量摘要，未修改登记源。CSMAR特殊处理变动表确有：

- `TypeAuditOpinbc`：变动公告前一年的审计意见类型；
- `ISSustManaNonStandExpl`：变动前一年是否因持续经营被出具非标意见；
- `Symbol`、`Annoudt`、`Execudt`：证券及特殊处理变动时钟。

但这是**按特殊处理事件组织的表**，不是全体公司—年度审计面板。4,158条源记录中意见字段112条为空，其余高非空率不能当作整个风险集的覆盖率。Annoudt是特殊处理变动公告日，不是前一年审计报告的首次实际公开日；缺少独立审计财年键、外部内控分类型、原版／更正版公开链。直接按这张事件表给“后来发生事件”的公司补特征，会引入事件选择信息，不能用于公平训练。

已有WRDS领域盘点仅显示审计师／IPO／再融资相关字段部分可见，6张相关表可访问但该盘点中下载数为0，未确认通用年度审计意见全历史表。检索中遇到的美国内控审计资源不属于本A股任务，未借用其语义。这是对已检查目录的结论，不是宣布其他来源不存在。

官方公告已证明可建立公司—报告年度—报告类型—版本—公开日的证据链；但本轮只检查事件案例，未测量全风险集正常企业的资料覆盖、误提取率或可用性。

后续允许启动的信息增量比较，最少需满足：

1. 按相同规则覆盖冻结训练／评价的全部公司，不按是否ST决定下载或填值；保留证券与公司组的原映射。
2. 财务审计、外部内控、公司自评、持续经营、重大缺陷和整改独立字段；保存原文术语及证据定位。
3. 每条字段有真实公开日、来源哈希和版本，严格小于原点；更正稿不能倒填。派生状态的available_at取其所有组成证据最晚公开时间。
4. 分开记录找到正常意见、未找到、未核验、未披露、明确不适用；不能把“缺报告”编码为正常。
5. 分开“历史曾异常”“最新意见”“整改完成／未完成／未知”，不能无限延续旧异常。
6. 采用同一经裁决标签、原模型与参数的含／不含审计信息比较；2023/2024仍是后暴露探索性，不用于选择配置。

当前可以完成上述字段规格；不能将事件专项取证直接宣称为 **AUDIT_INFORMATION_FEASIBLE_FOR_MATCHED_TEST**。本轮未启动全市场下载、LLM抽取、特征接入或训练。
