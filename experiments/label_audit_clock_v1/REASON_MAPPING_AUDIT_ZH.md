# 冻结样本原因映射核查

主要判断：**INDIVIDUAL_SOURCE_RECORD_CONFLICT**；不支持把“02”全局改为竞争事件。

登记范围为原显式目标原因码集合 `{01,02,03,04,05,08}` 分支涉及的235个冻结独立事件：训练172个、评价63个。所有事件均在私有清单中，包括47个仍未充分核验的事件，未只保留成功核验个案。

同一当前CSMAR `BDT_Trdchg.Chgreas`、版本 `m1-95399d76280a` 下“02”共6个冻结事件。源记录的文本均为“资产缩水”：2个训练事件与正式实施公告冲突；另外4个评价事件的正式实施证据支持负净资产等目标原因，其中一个通过本轮单份官方实施公告补证。若统一替换02，将破坏这4项本来有支持的目标分类。

第3个训练冲突来自其他原目标原因码，不计入同源02的两个冲突。正式证据支持目标不等于已证明所有历史首次事件与数据时钟无误。

字典明确了字段含义，但未提供完整原因枚举的历史版本。另一来源的 `STK_ITEMCHANGE` 使用 `ReasonID` 编码片段，不能因为末尾数字相同就当作同一命名空间；来源、字段、版本有一项缺失或不一致，均不能判同义。跨表枚举一致性保留 **MAPPING_SEMANTICS_UNRESOLVED**。

在已核验的其余同源02事件内，结论为 **NO_ADDITIONAL_CONFLICT_FOUND_WITHIN_CHECKED_SCOPE**，不扩展到全事件库。暂未证明统一原因映射缺陷；发现的是供应商个别记录与实施事实冲突，以及前轮独立的证据标题筛选缺陷。没有对原数据作字符串替换，也没有新增评价标签修订后的“更好性能”。
