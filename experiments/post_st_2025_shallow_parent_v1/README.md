# 2025年：固定深度4＋收缩，观察截止2026-06-30

这是用户指定的既有模型配置迁移实验。使用非金融行业首次财务／审计ST队列，重新计算下一交易日开盘前的保守C输入。训练入组年份2012—2024，训练信息严格早于2025-01-01，训练随访最多24个日历月。2025年结局截到2026-06-30。

q2继续使用83变量、深度4、32树／种子、三个既定种子和父节点AJ收缩强度10。普通RSF使用同一批训练／预测记录、同一公司bootstrap和此前固定的深度6等参数。它是完整配置比较，不是只有q不同的消融。

2025已被研究接触，本轮配置固定也不能重新称为盲测。主要评价12个月；24个月若没有随访支持，只报告事件、删失数量和保存的预测，不计算貌似完整的24个月AUC/AP/Brier。公司明细、模型、阈值、预测和完整函数均留在服务器。

运行入口依次为本目录的prepare、stages、launch和analyze。先执行完整测试；prepare恢复数据并复现所有390条历史C输入；提交并冻结代码后，stages生成独立的pilot/formal JSONL及hetero sidecar，用既有hetero-run提交；每阶段核对计算、回传和哈希后再继续。全部模型输出验证成功后才运行analyze。完整当前参考及历史实验不覆盖，不调参、不重新校准。

hetero-run将调度回执放在自己的auto-runs目录。调用stages的pilot/formal检查时，将启动日志中实际回执路径传给`--report`，并传`--job`；程序先核对任务命令身份，再留存本轮回执。回执位置差异不需要重新训练。
