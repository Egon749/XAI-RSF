# 数据与基线核验

沿用旧conservative C83，预测原点为首次财务/审计ST公告后的下一交易日开盘前。目标为先最终退市（原因1），竞争结局为先恢复（原因2）；不是恢复后再退市的总概率。拟合上限24个日历月，未知结局删失。每年1月1日前的信息形成训练集；2023/24/25训练企业309/345/390，退市14/26/49，恢复184/198/211；评价企业36/45/53。公司不跨当期训练与评价边界。

输入逐值等同已有83变量参考，数据哈希、缺失及字段顺序见COHORT_AUDIT.csv和FEATURE_AUDIT.csv。9个保存基线森林仅作重现核对，位置和哈希见ARTIFACT_REFERENCES.csv；实际重新拟合计入本轮预算。CURRENT_POST_ST_MODEL.json不改变。

本轮新增日期审计发现：历史fit_metadata中的部分财报描述仍是移动预测原点之前的旧描述。直接断言这些旧描述均早于新原点会失败：prev_available在2023/2024训练各1条、2025训练2条晚于原点。不能据此静默改数据，也不能把旧描述当成实际入模证据。

核对真实数据准备代码与权威information_alignment_PRIVATE.parquet、financial_availability_PRIVATE.npz后，确认实际刷新后的X与443条权威记录逐值一致。实际当前报告、市场和公告可得日均严格早于原点；48个财务字段的有效值均具有早于原点的字段级时钟。10项增长/变化指标逐项验证取所有组成数据最晚日期。权威上一期时钟确有8条晚于原点，但相应增长/变化值全部为NaN、对应时钟全部为NaT，没有实际使用未来组成值。旧元数据与权威记录差异计数完整保留于CLOCK_METADATA_RECONCILIATION.csv。本轮只改审计读取来源，不修改任何输入、标签、随访或原模型。

该日期检查不等于原始披露版本的独立认证；历史年报版本证据仍继承PROVISIONAL限制，没有采用后来研究者接受版本的替换输入。

2023/2024的12/24月有评价支持；2025的12月有支持，24月仍25家公司未知且无人达到完整时点，因此24月性能与校准标NA。2023的12月没有恢复事件，恢复AUC/AP标NA，Brier和平均风险仍有定义。详见FOLLOWUP_SUPPORT.csv。所有测试结局仅在冻结之后统一评价，不参与新增配置选择。
