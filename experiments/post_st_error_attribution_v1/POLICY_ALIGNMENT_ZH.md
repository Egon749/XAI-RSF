# 终局日期、实际触发依据与政策时钟

逐例关联既有权威事件审计、原始T／X公告文本和实际终局X公告日期，不按入组年份推定规则。31例测试终局均有日期和来源链，30例能识别明确依据，1例保持未知。2024训练截止前增加的8例旧队列终局也重新核查：7例明确财务／审计，1例依据未明确。未把后来的文字作为入组输入。

## 日期与规则不是同一个标签

| 测试终局的实际公告阶段 | 退市例数 |
| --- | ---: |
| 2024-04-12之前 | 4 |
| 2024-04-12至04-29 | 0 |
| 2024-04-30至10-29 | 21 |
| 2024-10-30及之后 | 6 |

按实际终局年份计数是2023年4例、2024年21例、2025年6例。2023入组企业中32家在2024-04-12前仍处于首次事件风险集，因此“2023入组”不能充当“未受2024政策影响”的对照。2024入组的45家在04-12前均未入组；04-30当天入组的29家不假定当天规则已经在预测时公开。风险集表按日期前一刻计算，未入组、已发生首事件和随访结束分别保留。

## 公告明确写明的依据

| 规则证据类别 | 事件数 | 默认Top20捕获 | 证据能够支持什么 |
| --- | ---: | ---: | --- |
| 既有1元股价条件 | 20 | 8 | 直接触发条件不是2024新设；不排除环境或政策间接影响价格 |
| 明确3亿元市值条件 | 1 | 0 | 不能因同时引用2024程序条款就改成5亿元条件 |
| 明确5亿元市值条件 | 2 | 0 | 确实引用调整后的门槛；未证明旧门槛下就不会退市 |
| 财务／审计或年报披露，明确2023版本 | 5 | 2 | 终局在2024，但公告采用旧版本触发依据 |
| 后续版本的财务／审计条件 | 2 | 0 | 需进一步逐条件比较旧规则，不能把版本较新直接当成新增政策效应 |
| 终局依据未明确 | 1 | 0 | 无法判定，保留未知 |

27例终局发生在2024-04-30之后，其中16例是1元股价条件、5例明确2023版本的财务／披露条件、1例3亿元市值条件。**时间落在政策之后不证明由新增门槛机械触发。** 同样，既有条件也不排除政策通过市场预期、融资或重组机会间接影响触发概率。

2024训练折中明确低价退市的支持由历史5例增至9例，仍没有明确市值门槛退市。测试期则有20例低价和3例市值退市。这里比较的是冻结队列内已观察到的原因构成，不是全市场退市统计；训练尚有删失，不能将原因构成变化解释为净政策因果效应。

## 权威规则核对

- 2020年上交所说明已经列出1元股价条件和3亿元市值条件；不能称低价路径在2024才出现。[2020年制度说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20201231_5294528.shtml)
- 2024-04-12的改革意见包括严格标准与削减壳资源价值。它支持政策机制假说，不能代替对本样本的估计。[证监会发布说明](https://www.csrc.gov.cn/csrc/c100028/c7473607/content.shtml)
- 主板市值调整有2024-10-30及旧情形延续的过渡安排；同一文件中的规则生效时间并不完全相同。[上交所通知](https://www.sse.com.cn/lawandrules/sselawsrules2025/repeal/rules/c/c_20240430_10785259.shtml)、[深交所通知](https://www.szse.cn/lawrules/rule/repeal/rules/t20240430_607069.html)

本轮不是完整的跨板块历史规则引擎；没有估计“无政策时这些公司会怎样”。没有建立DID对照、验证平行趋势或控制同时发生的市场冲击，不能给出政策解释百分比。两例5亿元引用也不能当作政策贡献率的上界或下界：其他路径可能受间接影响，而这两例也可能同时满足其他旧规则。
