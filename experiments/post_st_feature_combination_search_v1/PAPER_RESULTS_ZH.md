# 可用于论文的本轮结果段落

在保持q=2、最大深度4、共享切点、每树25项均衡覆盖及直接父节点AJ收缩不变的条件下，历史信息约束的组合搜索分别评价662、915和999组特征集合。2023截止点因历史事件支持不足保留83项，2024和2025分别选择74项，其中各有两项与既有74项方案不同。全部新增模型保持合法竞争风险CIF和完整二阶函数表示，最大重构误差为3.89×10⁻¹⁵。

相较83项参考，2025年12个月AUC由0.700升至0.767，AP由0.181升至0.254，Brier由0.084689降至0.083287，年度Top20捕获由2/5增至3/5。2024年12个月亦有有限排序收益，但24个月AUC从0.770降至0.670、AP从0.782降至0.659，捕获从8/20降至6/20。合并12个月AP基本不变（0.2469→0.2481），AUC反而下降（0.6451→0.6279）；合并24个月AP从0.6817降至0.5965。2025年24个月随访支持不足，不报告完整窗口性能。

2024和2025完整预测器的空间单元分别减少8.31%和7.20%，非零二元函数分别由146/147降至132/133，但50次固定特征集合的公司重抽样未显示一致的函数波动改善。上述结果说明，更充分优化稀少历史事件上的验证评分，并不保证未来预测或解释稳定性改善。选择器与外层评价的时间边界保持分离，但研究队列此前已暴露，且重抽样未重复完整组合搜索，因此结果仅支持探索性设计取舍，不支持将新集合认定为全局最优或直接替换现有研究参考。
