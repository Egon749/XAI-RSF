# 概率水平与候选覆盖：分开执行的有限实验

当前参考模型不变。本轮分别评价：①当前三种子森林的历史样本外受约束仿射校准；②保留q2，仅将每树候选资格25列改为全部83列。两项不组合，不更换深度、共享切点、父节点收缩10或节点mtry75。

校准按预测时点及期限选择最近两个已成熟年度队列：2023/24个月用2019—2020；2024/24个月用2020—2021；2023/12个月用2020—2021；2024/12个月用2021—2022。原始滚动预测由更早年份拟合，原模型与企业无交叉。按起点加期限选择，不按结局是否已知选择。历史完整端点恰无删失；不得把这一事实推广到原森林训练风险集。稀少原因不足10例固定其斜率为1，所有可估斜率限制[0.5,4]，目标是避免近常数化；此范围和20公司等效正则均事先固定，不宣称最优。

新校准采用当前森林的终端叶凸包Minkowski和作为输入域外包络，联合约束两原因概率；与旧“覆盖整个概率单纯形、斜率≤1”的实现区别明确。界限可能保守，约束激活或无改善也是结果。基准时间形状来自对应训练AJ，仅在12/24个月分别估计校准器，中间时点不宣称完成校准。

扩大候选资格会使尚未触及q上限的节点实际候选从25增至75；计算量不同是该机制的一部分。均衡调度在全部83列时自然无资格差异，但原随机数规则、bootstrap、深度与森林平均不变。不是IID25对照，也不加入两层前瞻搜索。

企业新增6次拟合；模拟沿用上一轮9场景×50份数据，只新增1350次wide83拟合，原q2及不限q结果保留为旧证据。本轮为看到旧结果后的匹配后续模拟。校准4次独立优化；另有2次新候选数值小试。所有正式臂保留raw与收缩版本，主分析三种子平均。未使用2025结局。

代码入口：`prepare.py --stage definitions/prepare/freeze`，冻结后以`hetero-run RUN/pilot.py`和`hetero-run RUN/formal.py`调度。输入通过DATA_DIR读取、输出写OUTPUT_DIR；发布后核验SHA256。完整来源、数据哈希、最终指标与解释验证在结果报告中交付。原始企业资料、模型、阈值、校准参数和公司函数留服务器私有目录。
