# 日历月评价更正

首次评价按实际天数合并反向Kaplan–Meier。当不同起点的24个月分别为730和731天时，一个已完整观察24个月的730天无事件记录会被错误用于减少另一个731天记录的G值。常数AJ基线合并AP变成0.344444，而81家公司都已知24个月结局，正确值应为31/81=0.382716。这一恒定预测自检暴露了评价问题。
