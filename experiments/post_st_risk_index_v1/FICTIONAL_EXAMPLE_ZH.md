# 示意：完全虚构的单公司分解

下列公司、概率、基准、变量名与贡献均为手工编造，未使用任何真实公司、模型参数或分级阈值。

假设固定365天基准为0.04，而这家虚构公司日历终点为366天，模型在该时点的基线为0.042。

| 示意项 | 虚构CIF贡献 | 换算指数分 |
| --- | ---: | ---: |
| 实际终点的基线 | 0.042 | 105 |
| 虚构因素A主效应 | +0.016 | +40 |
| 虚构因素B主效应 | −0.008 | −20 |
| 虚构A×B二元函数 | +0.010 | +25 |
| 合计 | 0.060 | **150** |

计算：105+40−20+25=150；150×0.04÷100=0.060。150分没有截到100，基线105也没有强行改成100。这里还原的虚构CIF为6%，并非150%。这些函数值是模型贡献，不是因果影响。

本例不提供“高风险”等标签：真实历史阈值尚未计算，不能凭150分自行确定档位。
