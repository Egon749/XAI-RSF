# 风险指数使用说明（定义已冻结，真实分级尚未完成）

风险指数是原预测换一种刻度：同年、同原因、同期限使用一个固定正基准，指数=100×原CIF÷该基准。基准来自该年森林在训练边际乘积分布下的函数分解；它不必等于实际训练公司预测的普通平均，更不是观察发生率。

在基准有效时，150分表示该预测是固定基准的1.5倍，**不是150%概率**；分数可以超过100。100分不是最高风险、百分位或必然事件。不能将不同年份、原因或期限的同一分数视为相同绝对风险。

完整解释的单位是“指数分”：基线项、全部主效应、全部二元项精确相加。正负贡献表示相对模型基线的增减，不是财务变量改变所造成的因果效应。公司12日历月可能对应366天，分母仍取365天；因此该公司的基线项可能偏离100，不能强行改为100。

由原版本对应的私有基准可逆还原：原CIF=指数×基准÷100。审计需同时核对年份、原因、期限、日历终点、森林/训练参考哈希、函数归一化约定以及分解/重载误差。仅凭一张分数表无法完整审计。

对CIF和基准同时乘同一正数，指数不变。这意味着它不依赖单纯的乘法水平放大，**也意味着它没有修复原模型概率低估**。同年排序、AUC/AP和Top20理论上不变，不能说重新获得更强预测信号。

高/中/低档拟按历史OOF指数的80%、50%分位阈值划分，同分不拆档；历史不足30家则不分级。固定阈值下，当期高风险档可能不是20%。汇集各历史模型自身归一后的指数，是一个冻结的经验分档规则，不自动证明跨年同分同风险或阈值可迁移。

**本轮实际状态：2019年退市历史基准不满足正分母条件，尚未生成合法历史阈值或2023—2025档位。** 不应拿原Top20、当期百分位或训练内指数替代。先报告阻塞，不把不可定义的0/0填0、100或任意常数。
