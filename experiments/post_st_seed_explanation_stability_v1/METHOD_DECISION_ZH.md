# 对论文主张的判断

**数学主张得到支持，稳定性主张需要限定对象。** 三个年度、两个叶估计版本、全部120组三种子组合都能精确分解。公司风险排序比个体解释项目更稳定，主效应集合比二元交互集合更稳定。

| 研究问题 | 本次证据及可用表述 |
|---|---|
| 企业预测对种子敏感吗 | 对于完全不共享成员的96树组合，三年12个月退市排序的相关性中位数为0.930、0.929、0.968。2024年前20%只核查9家，两套组合的名单Jaccard中位数为0.500，且120组的捕获数从6到9变化。即使排序相关较高，具体核查企业仍会变化。 |
| 全局及局部解释稳定吗 | 三年不共享成员的主效应集合Jaccard中位数为0.738–0.779，交互仅0.183–0.197。2024年12个月退市的企业前五项解释Jaccard中位数为0.500。稳定性应按变量、时限、原因及数据支持区域说明。 |
| 有可重复的模型规律吗 | 若干审计主效应和近月最大回撤通过三年365天退市描述筛查。2025年最近股价对数与持续经营审计提示的交互有较一致的形状和联合事件支持；前两年缺少同等证据。可写成样本内可重复模型模式，跨制度期或跨人群的经济机制为 INCONCLUSIVE。 |
| 三种树预算如何权衡 | 32树较易逐项查看。以固定原96树为锚，增加到三成员通常能使预测更接近锚点。320树进一步增加解释表规模，2024年12个月退市排序与锚点的相关从三成员中位数0.907升至0.917，同年交互数从中位数131升至317。2025年筛查捕获则由原96树的3/5变为320树的2/5。未验证统一最佳树数。 |
| 能否证明方法主张 | 可写“森林输出具有完整、可检验的二阶加性表示，若干重要主效应在固定训练数据的种子扰动下可重复”。不能写“每个企业的驱动因素唯一、所有交互稳定、选定种子为最优、概率低估已修复、已证实财务机制或因果效应”。 |

**论文方法段落。** 在固定各年度训练样本、结局时钟、74项输入、分裂与叶估计设置的条件下，我们枚举十个已有种子中全部三成员组合。以三份32树预测的等权平均构造96树预测器。解释按年度训练边际乘积分布中心化。我们用全部训练企业的联合分布比较非空区域上的贡献函数，分别评价结构选择、函数形状、幅度、实际事件支持及同一企业的局部归因。鉴于组合间共享森林成员，结果按共享种子数量分层，区间描述指定成员集合内的敏感性。

**论文结果段落。** 720份年度组合表示均通过全训练及评价样本、全部原生时间点和两种原因的重构与概率检查。完全不共享种子的组合在2024年12个月退市任务上具有较高的企业排序一致性（Spearman中位数0.929），但二元函数集合和个体前五贡献的Jaccard中位数分别为0.183和0.500。这提示精确性可用于逐项核查一次预测，而关于解释可靠性的表述仅适用于通过跨种子幅度、方向和联合样本支持检查的具体函数。全部队列及种子均曾被查看，本实验属于探索性机制审计。

原96树作为固定参照保留。本实验未选取新的正式模型。
