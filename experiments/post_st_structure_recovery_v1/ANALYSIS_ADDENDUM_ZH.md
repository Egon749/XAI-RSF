# 分析补充记录：边界检出率区间

在正式效应估计尚未查看、拟合仍执行时，为二元检出率补充统一的Wilson95%区间。原冻结协议的均值、标准差、MCSE、t型均值区间及全部配对差值均保留。

原因：50次重复若全部检出或全部未检出，经验标准差为0，t型区间退化成一点，不能据此声称真实检出概率严格为1或0。补充规则同时适用于所有场景、两个模型、raw/收缩、种子/合并、时点和原因，不根据优劣挑选区间。

仅对单个真实函数的检出、方向正确、方向正确检出及只有一个真实二阶项时的二阶召回率计算二项Wilson区间；不对precision、多函数平均recall、连续幅度或配对差值套用二项公式。

图中二阶检出率采用Wilson区间，连续指标继续采用冻结的t型均值区间。原始t区间同时保留在CSV。此补充不改变任何数据、模型、种子、门槛、拟合数或主要幅度评价定义。
