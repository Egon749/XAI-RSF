# 数据与协议审计

本轮确认使用CURRENT_POST_ST_MODEL.json所指C039：74列，种子17/503/22，各32树。按指针记录逐个核对9个源森林及预测哈希；所有配置与现有配置接口一致。没有采用刚才诊断的PROBoost。

训练X和标签均取对应预测年度自己的历史快照。元数据sample_id顺序、事件和时间与数组一致；origin、stop严格早于当年1月1日，stop不晚于origin加24个日历月。每家公司一行，训练和评价ID无交集。只按origin所属年份筛行，不回填后来知道的恢复或退市，不改变仍未完成观察的删失记录。

每个起始年、截止年、时限的公司和事件支持见TRAINING_SUPPORT.csv。83→74的既有特征选择、C039种子选择和保守C财务披露版本局限均继承；本轮没有重新认证原始财报版本，不能宣称新的独立PIT认证。2023—2025结局此前已经查看，全部比较为探索性。

完整2012起始臂也重新拟合，用于检验与原C039的树结构、全部原生时点预测和已保存测试预测一致。主模型及旧工件均不改变。实际训练从最早入组年一直延续至对应预测截止日前，而不是只使用该起始年度。

数据量减少后，bootstrap抽样池、训练分位数切点、AJ风险集和函数参考分布会自然改变。相同种子保证随机算法可复现，不能声称不同窗口用了完全相同的公司bootstrap。74列顺序和每树变量覆盖设置保持一致。

所有测试年度公司集合固定。2025年24月只保存预测、检验概率及函数；不填补未成熟结局，不计算性能。固定预测的1000次公司分层bootstrap仅反映评价样本波动，不包含训练样本变化、种子/窗口选择不确定性，也不用于选择新主模型。
