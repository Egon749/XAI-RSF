# 70—120棵统一比较：重点24个月先退市

**24个月结果没有一个跨年度、跨指标都最好的树数。** 2023年AUC最高仍是96树（0.7708），2024年AUC最高为117和120树（均0.6980）。两年合并AUC/AP最高是117树（0.7003/0.6328），合并Brier最低是120树（0.3158），Top20合计捕获最高却是78树（12/32）。这些是本轮17个固定点的描述性极值，不能据此证明真实最优树数或自动替换当前模型。

新增72、75、78树后，有三点需要单独说明：

- **72树在2023年的AP最高（0.6686）**，但AUC低于96树（0.7604对0.7708），2024年Top20只捕获6/20，对比96树为7/20。不能因为2023年AP较好就认定全面改善。
- **78树的24个月捕获较好，表示更小。** 2023年捕获5/12，比96树多1个；2024年仍7/20，合计12/32而非11/32。2023年AUC降到0.7535，2024年AUC仍0.6700；合并AUC从0.6901降到0.6881，AP从0.6082变为0.6091。两个年度平均空间单元从2777降到2402.5，减少13.49%；二元函数从135.5降到117。但2023/2024平均二元函数集合Jaccard从0.1155降到0.1037，共同函数在730天退市输出上的相关性均值从0.4705降到0.4256，不能说解释稳定性同步改善。
- **117—120树主要改善2024年排序，增加了表示规模。** 相对96树，117树2024年AUC提高0.0280、AP提高0.0396，但2023年AUC降低0.0139、AP降低0.0468；两年Top20仍11/32。117和120树平均空间单元分别3217和3303，比96树增加15.84%和18.94%。集合重合度有所提高，形状相关性没有一致提高；这些诊断比较的共同函数集合也随树数变化。

不确定性仍明显。117树减96树的24个月合并AUC差为0.0102，固定预测条件下95%配对区间为[-0.0052, 0.0261]；AP差0.0245，区间[-0.0069, 0.0595]。2024年AUC差0.0280的区间为[-0.0021, 0.0660]。78树多捕获1个事件的配对区间为[-1, 3]个，不能证明稳定增加。117和120树的合并Brier差分别-0.000885、-0.001110，描述性区间分别[-0.001683, -0.000062]、[-0.002038, -0.000189]；绝对改善很小，且多次已暴露比较后的区间不构成确认性优越证据。

**树数改变没有解决绝对风险低估。** 96树24个月平均预测为2023年6.92%、2024年11.86%，观察发生率为33.33%和44.44%；117树仅变为6.91%和12.00%。合并Brier略降不能被写成概率校准已经充分。

次要结果也存在代价：78树12个月两年加2025年合计Top20捕获为12/25，低于96树13/25；117树同为12/25。78树24个月恢复原因合并Brier从96树的0.2390恶化到0.2411，117树为0.2394、120树为0.2398。因此本轮不按不同年度或不同结局拼接各自赢家，也不改变原参考模型。上一轮105树的优势是所声明的12个月年内AUC点估计，不能移用到24个月。

实际完成36/36项补充导出，两节点计算和发布均成功；森林拟合、校准拟合和新增树均为0。408份新旧模型/函数表示全部通过验证，完整重构最大误差2.665e-15，独立逐项求和最大误差3.220e-15，路径不同变量数均不超过2。278项测试通过，包括独立R检验；没有失败任务或删除不利结果。2025年24个月因随访不足保留NA。


## 范围和执行口径

固定74输入、退市支持保护、q≤2、深度4、共享5切点、均衡25变量池、直接父节点AJ收缩10、各年1月1日前历史数据以及24个日历月训练随访。比较的是森林树数，不是改变训练随访或预测时点。三个种子42/101/202树数相同、等权平均；70—120总树数范围中可用72、75……120共17档。70和71不能分成三个相同整数树数，没有改变权重来凑端点。

复用81—120全部336份表示，只补72、75、78的36个独立联合导出任务（72份raw/收缩表示），仍全部采用已保存森林的原编号前缀，无新森林、校准器或树拟合，无重复收缩。沿用上一轮120树资源试运行，未重复计算试运行。合计153份种子模型、51份合并预测器，raw/收缩共408份表示。旧81—120的全部年度、种子、版本、原因和时限指标逐值复现。

这是在此前已暴露树数结果后的有限扩展，协议先于新增72/75/78指标提交。24个月单独展示，不把上一轮以12个月排序得到的105树结论改写为24个月最优。只列不同指标各自极值，不构造事后综合评分，不自动替换96树，不按年度选不同树数拼接表现。
