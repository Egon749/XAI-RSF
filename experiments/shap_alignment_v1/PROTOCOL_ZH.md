# 已保存森林的 TreeSHAP—完整函数对齐消融

这是解释口径实验，不是预测器重训。复用当前 old-C、深度4、q2、父节点AJ收缩强度10的2023/2024模型，以及同任务已冻结的randomForestSRC 3.9.0参照；每年种子42、101、202，每个森林32棵树。保留原预测与研究默认版本，不读取2025，不使用测试结局选择解释样本或变量。

所有训练与验证特征记录均参与数值核验。2023验证36条、解释时点731日；2024验证45条、时点730日，分别对应各年记录的24个日历月。训练参考分别309/345条，两折训练集重叠，不能相加称独立企业。统一解释“先最终退市”的CIF，适配器的raw输出已经是CIF，不能再做logit或累计风险率变换。

## 三组主比较和一个必要的对照

1. 标准RSF＋默认TreeSHAP。调用`shap.TreeExplainer(model_dict)`，不传背景、不覆盖`feature_perturbation`。固定并记录SHAP版本及实际解析方式。
2. 同一个q2森林＋精确边际乘积背景下的SHAP交互值。比较全部对角项与保存的主效应函数、全部非对角项与保存二元函数的一半。
3. 同一个q2森林＋默认TreeSHAP。按照同一交互矩阵口径比较，避免把普通单变量SHAP与原生主效应直接混为一谈。
4. 标准RSF＋同样的精确乘积背景，仅作机制对照：直接测量三阶以上函数如何进入普通Shapley归因。否则“默认背景变化”与“高阶分摊”会混在一起。

依赖图的纵向分散也可能由二阶交互产生。因此同时画q2的普通SHAP作为对照，不把散点纵向分散当作三阶以上交互存在的证据。高阶存在性由完整的、所有实际阶数的中心化函数展开核验。

## 默认背景及软件限制

本环境SHAP 0.54.1在不传背景时解析为`tree_path_dependent`，用保存的树路径样本计数。它不是一般意义下精确的条件分布SHAP，也不等于训练经验边际的乘积。

原生`interventional`交互接口在小型数值探针中提示`FEATURE_DEPENDENCE::independent does not support interactions!`并返回全零。该全零结果不用于正式比较。将训练各列独立打乱后拼成有限行也不等于精确乘积背景，不能据此要求机器精度对齐。

这里对每个树节点对应的矩形区域，计算其在训练经验边际乘积下的精确概率，并仅替换解释器的区域权重。切点、缺失方向、叶输出、树数及预测完全不变。该背景下子节点/父节点区域概率比正好是TreeSHAP递推所需的条件分支概率。官方TreeSHAP在这些权重上计算交互值；另一个独立实现按每个叶区域的全部联盟及阶乘权重计算Shapley值与交互值。正式结果还与事先保存的q2函数文件比较，不通过把函数除以2来伪造独立验证。

## 对齐公式与边界

固定参考`Q=⊗_j Q_j`，使用中心化函数ANOVA及同一个联盟游戏：

`v_x(S)=E_Q[F(x_S,Z_{-S})]`。

对纯r阶函数`f_U`，其给成员j的普通Shapley贡献为`f_U/r`；给成员对j,l的对称矩阵单侧贡献为`f_U/[2(r−1)]`。对角项由行和减去非对角项得到。

因此q2时：`Φ_jj=f_j`，`Φ_jl=f_jl/2`，以及`φ_j=f_j+Σ_{l≠j}f_jl/2`。r≥3时高阶项也会进入SHAP的单变量及二元矩阵分摊，不能把SHAP对角线一概理解为纯一阶函数。

这些等式是给定参考与归因定义后的代数关系；本实验检验实现正确性和背景依赖性，不宣称发现新的Shapley定理、不证明因果性或统计可辨识性，也不证明q2预测优于RSF。

乘积参考会打破变量间的依赖，可能组合出实际未观察到的财务或审计标记状态。它提供统一、可分离的函数中心化基准，不因此成为真实联合分布或条件分布。默认路径背景与乘积背景回答的归因问题不同；本轮不把其中一种解释定义自动认定为更真实。

## 冻结检查和图表

- 数值相等检查绝对容差1e−12；同时报告实际最大误差及RMSE，不调宽阈值。
- 逐样本、逐树验证RSF的原生叶节点归属；核验原预测、保存预测和适配器预测；另加入切点及相邻浮点值探针。

- 全部83个输入、全部二元矩阵元素、所有实际高阶函数参与检查；图中如抽样散点必须标注，不能缩小数值验证范围。
- 依赖图变量按训练参考上的平均绝对普通SHAP选择：每年标准RSF/default第一名与q2/product第一名；不按测试结局或最大不一致程度选择。
- 企业级依赖图、交互散点、函数值、真实阈值和预测留私有目录。Git仅提交通用代码、协议、汇总CSV/图和哈希凭据。
