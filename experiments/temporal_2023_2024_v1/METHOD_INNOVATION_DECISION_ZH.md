# 2023/2024时间外评价：研究判断

**正式结论：INCONCLUSIVE。** 本轮训练、预测与完整解释验证执行成功，但没有保住标准RSF M2的AP和主要预警覆盖；高风险区随访/源资格缺失及历史PIT限制，又使正式概率校准和总体泛化结论不能确定。因此不能把“6个模型跑通”写成“方法创新已经成功”，也不以记录等权Brier的小幅优势宣布优于M2。

## 1. 已获得的直接证据

最终训练集87,134条记录、283个独立目标事件；相同最终模型分别用于2023的18,162条、2024的18,606条记录。当前coverage与同后端不限阶数对照各3个固定种子，6/6完成；M2复用冻结预测。本轮没有测试调参、最佳种子筛选或逐年再训练。

记录等权、三个种子指标均值：

|评价原点|coverage AUC / AP|M2 AUC / AP|coverage相对M2 AP保留|Top20 coverage / M2（独立事件分母）|
|---|---|---|---:|---|
|2023|0.827433 / 0.097264|0.860482 / 0.135388|71.84%|53.33 / 58.33（83）|
|2024|0.826456 / 0.094958|0.859592 / 0.153232|61.97%|48.67 / 66.00（99）|

coverage相对M2的AUC差约0.033；AP和Top20覆盖的差距更有实际影响，特别是2024年平均少捕获17.33个独立事件。相对同后端不限阶数对照，2023、2024的AP分别保留78.61%、73.59%，Top20分别少5.33、11.00个事件。它们是固定配置的描述性比较，不是统计显著性结论。

2024年两者AUC差距（coverage相对同后端参照）只有约0.0063，但AP与Top20覆盖仍明显落后。这说明不能单靠AUC接近就说高风险识别已经保住。Top25有所缓解：2023 coverage 64.33/83、M2 66.67/83；2024分别65.67/99、77.33/99。不能因Top25更好看而事后替换原主要Top20口径。

三种子平均预测的集成另列报告，结论不因这种聚合消失：2024 coverage AUC 0.827124、AP 0.097069、Top20 47/99；M2分别0.861068、0.156834、69/99。不得把集成和指标均值交叉取值。

## 2. Brier与校准必须分开判断

记录等权Brier中coverage比M2低约0.41%（2023）、1.71%（2024），是有限的正面结果；公司等权时coverage反而更差：2023为0.015409对0.014435，2024为0.018702对0.017960。因此“Brier更好”不能不加权重口径地概括。

更关键的是，在三种子集成的最高风险十分位，coverage没有正评价权重的比例为69.9%和75.9%，M2为22.3%和24.4%。所有模型保留相同原风险集和相同未知处理规则，未把未知当正常。但当前可解释模型的高分更集中于未知来源状态记录，这是需要保留的负面发现；可能涉及质量/缺失语义与分裂结构，**本轮尚未证明具体原因**。

全体预测均值高于继承IPCW观察率，且高风险区未知集中，不能直接据此宣称模型已校准或系统性高估多少。边际独立删失假设在这里尤其需要审计。未知企业不属于已知误报，不能删除后重排再用好看的数字替换主结果。

## 3. 完整解释成立，简单与可靠仍有边界

三个coverage模型分别有23/25/26个非零主效应函数、42/41/42个非零二元函数；空间格1330/1234/1387，平均1317；全时间与两个原因的标量格平均726,984。全评价样本、全原生时间的最大重构误差1.388e-16，保存重载误差为0，无路径阶数违规。

这支持“森林完整CIF可以精确表达为主效应与双变量函数”，不是SHAP代理近似。它不证明函数表已足够简单。跨种子主效应集合Jaccard为0.500—0.594，交互仅0.339—0.361；共同交互的相关性中位数0.789—0.887，符号一致率中位数0.719—0.776。共同项相关性不能掩盖大量交互未共同入选。

空间格的低支持比例为9.25%—14.02%，零支持为7.89%—11.43%；每个coverage森林仍有65—69个叶没有竞争事件公司支持。这不破坏代数重构，但限制稀少竞争事件与部分交互函数的统计可靠性。

## 4. 整体框架和独立创新分开

整体框架的工程价值仍然成立：保留bootstrap生存树、存活分裂、叶AJ估计和等权森林平均；通过路径q2限制得到完整、可重构的内生CIF函数。当前结果还表明这种结构约束伴随可测量的预测代价，后期AP保留比开发期更弱。

本轮无可辨识性惩罚、无硬分区预算，不检验早期newRSF2信息矩阵准则。coverage与不限阶数对照同时存在路径阶数、共享切点和树级候选资格差异，不能把全部预测差距归因于q2，也不能据此证明某一组件独立增益。低阶约束、精确分解本身的既有文献边界仍适用；本轮没有建立“相对已有方法的独立原创贡献”证明。

## 5. 本轮停止点

保留全部成功模型、未知结果、局部支持不足及不利比较，不继续根据2023/2024结局调参。这两年现在明确属于已接触的回溯评价资料，不能以后重新包装成严格盲测。当前配置尚未达到“保住标准RSF预测性能且解释可靠”的联合目标；是否构成可用于论文的独立方法创新，仍需独立机制证据和可信的时间/随访口径，本轮不能肯定回答。
