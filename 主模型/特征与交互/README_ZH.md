# 74变量主模型：实际使用字段与函数重要性

**三个年度分别实际使用61、57、54项输入。退市主效应的共同核心是审计状态、持续经营疑虑和市场回撤；交互可以完整精确核对，但跨种子重复出现的证据较弱。** 本次只读取已保存的9个种子模型、3个96树合并模型、完整函数与冻结X。没有重新训练、校准、使用评价结局或筛选新变量。

模型：`post_st_drop9_support_v1/drop9_support/shrunk`，74列、q2、深度4、每树25个候选变量、共享切点、均衡覆盖、退市支持保护、直接raw父节点AJ收缩10。原83项冻结指针及历史结果保持不变。2023—2025为已暴露年度的探索性解释诊断。

## 如何计算

- 实际使用：检查96树的分裂节点；变量仅进入候选池不计使用。完整清单见 [全部74项使用清单](全部74项使用清单.md)。
- 函数：使用已保存的精确分解。中心化参照是该年度训练数据的边际分布乘积，幅度则在该年度实际训练公司的联合观测行上求平均。训练参考样本分别309、345、390家。相关变量可能导致参考分布覆盖实际罕见组合；完整重构不等于统计可辨识性或因果识别。
- 重要性：主效应为 `100 × mean(abs(f_j))`，交互为 `100 × mean(abs(f_jl))`，单位是CIF百分点。先平均三种子函数，再取绝对值；不等于三个种子重要性直接平均。只描述模型使用贡献的幅度，不是删除后的AUC损失，也不表示该变量恒定升高风险。
- 显示时点统一为365、730天，对应12、24个月函数展示。原预测评价使用逐公司日历终点（365/366、730/731天），本次不重算性能。2025年730天函数可以计算，但24个月真实预测性能仍为NA。
- 下面重点报告原因1（先最终退市）；原因2（先恢复）的完整结果同样保存在CSV。主效应和交互分开排名，不把交互任意归给其中一个变量。
- 三种子最小—最大值用于描述算法随机性，不是置信区间。函数相关性只在共同非零函数上计算；二元标记的相关系数可能为1而幅度仍不同。跨年参考样本及模型均改变，不能把跨年幅度变化直接解释为制度影响。

## 可以支持的结论与边界

1. 标准无保留意见标记在三年、两个时点的退市主效应中均居首位。持续经营疑虑、无法表示意见、近1个月最大回撤也反复出现，表示模型主要沿审计信息及市场风险作区分。这里只衡量幅度；不能把“标准意见重要”写成“标准意见增加退市风险”。
2. 财务变量没有消失。现金/短债、总资产周转率、资产减值损失、应收账款周转率等在不同年份具有较大主效应，且还可能通过交互参与。
3. 交互总体贡献并非零：在12个月退市解释的所有主效应与交互平均绝对幅度之和中，交互占比分别为35.34%、32.82%、29.11%；24个月分别为31.51%、28.82%、26.55%。这些比例不是概率份额，不能用来证明交互改善AUC。
4. 12个月退市交互在三个种子都非零的只有2、0、1组。其中“近3个月收益5%分位×标准无保留意见”在三个年度均出现，但2024仅2/3种子非零；2023/2025虽3/3出现，其最小种子间相关分别约0.354和0.471，幅度也有波动。2025最强的“股价×持续经营疑虑”仅2/3出现。可称反复出现的候选搭配，不能称已验证的稳定经济机制。
5. 74项是输入维度，61/57/54是树实际使用数量，57/52/50是训练参考行上的12个月退市非零主效应数。三者回答的问题不同。没有发生本轮特征删除，也没有据此改动主模型。
6. 现有模型的解释是精确的；函数选择和幅度的可靠性仍需更多历史窗口或真正独立数据支持。函数图或平均绝对贡献无法单独证明不可替代预测贡献；需要训练期重训消融才能回答那个问题，本轮未做。
